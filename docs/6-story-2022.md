# 6. 项目背景：2022 年竞赛项目与本仓库的关系

## 当年的项目

**第十五届国际先进机器人及仿真技术大赛 · 创新设计赛 · 一等奖**（中国仿真学会主办，2022 年 11 月）。

作品是一艘遥控双体水面垃圾清理船（团队"海丝一队"）：吃入式收集 + 侧推进器零半径转向 + 船载垃圾识别。算法部分的工作链路：

1. **自建水面垃圾数据集**——当时公开数据集以水下为主、与水面成像差异大、细分类稀缺，因此在校区水域布放典型垃圾并按作业视角自采，结合公开水面数据构建数据集（约 1.4 万张，8:1:1 划分）；
2. **YOLOv5 训练**——单阶段选型 + COCO 迁移学习 + 300 epoch，总体 P/R/F1 = 0.909 / 0.893 / 0.897；
3. **Jetson Nano 量化部署**——层合并 + 精度压缩，FP32 6/11 FPS → 量化后 10W 档 18 FPS，实船运行；
4. 校区水域实测 + 比赛现场演示。

完整技术细节见同目录 [tech-report-2022.pdf](tech-report-2022.pdf)（赛后复盘整理稿，含局限性分析）。

## 为什么"复刻"而不是直接开源当年代码

- 当年训练用的是**自建数据集**（含自采图像），不适合直接公开；
- 当年的训练/部署环境已过时（PyTorch 1.12 / 2022 年的 ultralytics 生态），照搬对今天的用户没有复现价值。

因此本仓库做的是**管线复刻**：用两个公开水下数据集替代私有数据，把当年的工作链路（数据集构建 → 统一训练 → 评测 → 边缘导出 → 实时演示）用 2026 年的工具链重写一遍，并补上当年没做的架构对比（v5n / v8n / v11n 同协议）。

## 与当年工作的对应关系

| 当年（2022） | 本仓库（复刻） |
|---|---|
| 自建水面数据集（私有） | Trash-ICRA19 + TrashCAN 公开数据集 + 转换脚本 |
| YOLOv5 + COCO 迁移学习 | 相同思路；另加 v8n / v11n 同协议对比 |
| 自建集上的 P/R/F1 评测 | unified test split 评测 + 延迟基准 |
| Jetson Nano INT8 量化部署 | ONNX 导出 + TensorRT 部署路线文档 |
| 船载实测 | USB 摄像头实时演示 |

## 关于当年指标与复刻指标

两套数字**不可直接比较**（数据集、划分、评测实现都不同）。当年指标见技术报告；本仓库 README 的基准表是复刻环境下的实测。硬要一句话概括：同量级、复刻版因数据更"干净"略高。
